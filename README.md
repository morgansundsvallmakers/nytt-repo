# nytt-repo

Tillfällig startyta för nya projekt.

Det här repot är avsett som en enkel landningsplats när en idé ska kunna börja byggas direkt, till exempel från telefonen via ChatGPT/Codex. Innehållet kan senare utvecklas vidare, flyttas eller ersättas när projektet fått en tydligare form.

## GitHub Pages

Roten innehåller en enkel `index.html` som kan användas för att initiera GitHub Pages.
